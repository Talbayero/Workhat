# Compliance Documentation

This folder contains compliance-oriented policy, readiness, and evidence documentation.

## Contents

| File | Purpose |
|---|---|
| `soc2-readiness.md` | Active SOC 2 Type 1/2 readiness map, evidence inventory, and gaps |
| `accessibility-audit.md` | WCAG 2.1 AA accessibility audit evidence |
| `WorkHat_SOC2_Gap_Analysis.docx` | External/internal SOC 2 gap-analysis artifact |
| `../POL-*.docx` | Approved policy documents currently stored in the main docs folder |

## Evidence Guidance

For SOC 2 Type 2, store or link dated evidence for recurring controls. Examples include access review results, change approvals, incident logs, vendor reviews, test runs, deployment records, and monitoring reviews.
